# 临床工具 · 医学知识速查

一个单文件、离线可用的医学知识速查工具，覆盖 **11 个模块、4378 条记录**：

| 模块 | 图标 | 说明 |
|------|------|------|
| 院前急救 | 🚑 | 急症处理、夜班急症 |
| 药品速查 | 💊 | 常用药、皮试配置、配伍禁忌、急救药品 |
| 疾病医嘱 | 🩺 | 各内科/外科/妇儿等疾病医嘱 |
| 症状鉴别 | 🔍 | 按系统/部位的症状鉴别 |
| 医学计算器 | 🧮 | BMI、BSA、MAP、eGFR、滴速等 |
| 检验检查 | 🧪 | 血常规、生化、影像、血气等 |
| 泵入药物 | ⏱️ | 循环/呼吸/镇静等泵入用药 |
| 病历模板 | 📋 | 各科室病历模板 |
| 临床指南 | 📖 | 各专科临床指南 |
| 操作技能 | 🛠️ | 生命支持、侵入性操作 |
| 医疗文书 | 📄 | 证明/同意书/记录等 |

## 功能

- 全站搜索 + 拼音首字母搜索
- 响应式设计：手机 / 平板 / 电脑自适应
- 深浅色主题（跟随系统）
- **多用户**：注册 / 登录后，增删改与收藏**按账号分别保存**
- 每个模块的记录都可**新增、编辑、隐藏/删除、导入（JSON）**
- 收藏夹、打印

## 本地使用

直接用浏览器打开 `index.html` 即可，无需联网、无需安装。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录推送上去；
2. 仓库 `Settings → Pages`，Source 选择 `main` 分支、根目录 `/ (root)`，保存；
3. 稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 关于登录与账号

- **本机账号（用户名 + 密码）**：完全可用，数据保存在浏览器本地存储（`localStorage`），按账号隔离。
- **微信 / QQ 登录**：按钮已就位，但真正的第三方 OAuth 登录需要**后端服务**与微信开放平台 / QQ 互联的 **AppID**。纯静态托管（GitHub Pages）无法直接实现，需要接入后端（如 LeanCloud、Supabase 等）并把 AppID 配置到代码中。

> ⚠️ 本工具为知识速查辅助，不替代临床判断。用药请核对最新说明书与指南。

## 数据说明

- 内置数据以 JSON 形式内嵌于页面（`<script type="application/json">`）。
- 用户对内置记录的「编辑/隐藏」以及「新增」记录，以覆盖层形式保存在各自账号的本地存储中，不改动内置数据。
